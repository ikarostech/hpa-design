# 尾翼・全翼面VLMの計算基盤

2026-09-28: `TAIL_ANALYSIS_HANDOFF.md` の最初の範囲に着手。最初の実装単位はメッシュ生成と非粘性VLM API。後続の節に画面・解析ケースへの接続を記録する。

## API

- `createTailAnalysisMesh(surface)` は尾翼単体のメッシュを生成する。
- `createAircraftAnalysisMesh(aircraft)` は主翼と全尾翼を結合する。各パネルは `surfaceId`、左右、断面間のストリップ番号、コード方向番号、翼型参照を保持する。
- `calculateAircraftVlmCoefficients(mesh, condition)` は全パネルの相互誘導流を一つの影響係数行列で解く。単独翼面の結果を加算する方式ではない。
- 既存の `calculateVlmCoefficients` は主翼用の従来APIとして維持する。

尾翼はセクション間のスパン長を上反角で投影し、ねじりは局所の1/4コード軸、取付角は翼面の原点を通る軸のまわりに適用してから根元位置へ移動する。水平尾翼は左右の形状を生成し、`symmetric` は右翼型参照を左右へ適用する。通常の単垂直尾翼と左右Double Finに対応する。単垂直尾翼では右翼型参照を使う。Double FinはY根元位置を ±Y に配置し、左右を鏡像にする。Y=0で重なるDouble Finと未対応のSymmetric Finは例外で拒否する。

## 座標・係数・符号

- Xは後方、Yは右、Zは上。位置・長さはm、角度は度。
- 正の取付角・ねじりは後縁を下げる。取付角はメッシュへ適用済みなのでソルバーで加算しない。
- 単位流速は `(cos α cos β, sin β, sin α cos β)`。正のβは流速のY成分が正。
- `reference` に基準面積S、スパンb、コードc、モーメント参照点を明示する。単体解析では尾翼寸法、全機解析では主翼寸法などを呼び出し側が指定する。参照点を幾何学中心や中立点から推測しない。
- `force` は動圧で除した非粘性の循環による力（m²）、`moment` は参照点からの位置ベクトルとその力の外積（m³）。各パネルと全体で同じ定義。
- CLは迎角で傾いた揚力軸 `(-sin α, 0, cos α)` への力をSで除した値。CYは機体Y方向の力をSで除す。
- CmはYモーメント/(Sc)、CrはXモーメント/(Sb)、CnはZモーメント/(Sb)。外積に従う右手系で、正のCmは機首上げ。
- CDiは後流誘導速度による抵抗の集計をSで除す。循環による `force` と別に返し、負の集計は既存VLM同様0に制限する。これは総抵抗CDではない。

## 検証と限界

テストは尾翼配置、局所ねじり、翼型参照、単FIN・Double Fin、独立した取付角、吹き下ろしによる尾翼荷重の減少、横滑り符号反転、パネル荷重保存、参照点と基準面積の変更を確認する。既存主翼APIのAVL比較テストも維持する。尾翼・全機について外部ソルバーとの数値一致はまだ検証していない。

全翼面VLM API自体は薄翼・非粘性・小角度の計算基盤。後流は既存ソルバーと同じ固定+X方向。翼型参照は保持するがPolarによるキャンバー、Re別粘性抵抗、翼型モーメント、失速・範囲外判定は反映しない。結果からトリム・安定性の合否を判定しない。胴体、舵面、動安定性は対象外。

## 尾翼単体解析への接続（2026-09-28）

`analyzeTailSurface` は速度・密度・動的粘性係数から各ストリップの局所Reを求め、各面の左右翼型についてReと角度を囲む、状態が `complete` のPolarだけを線形補間する。翼型Polarが無い、`needs-review`、またはRe・角度がデータ範囲外の場合も、VLMが解ければ `inviscid-only` として揚力・横力・誘導抵抗を返す。断面抵抗・総抵抗・モーメントは未算出とし、不足理由を表示する。Polarの外挿はしない。入力・形状またはVLM計算そのものが成立しない場合は `unsupported` として理由を返す。コード方向分割数は局所Reの翼弦長を変えない。Double Finでは2枚の合計面積を係数基準とする。

現段階でPolarから使うのは断面CD・Cmだけ。CL・零揚力角・失速域・非線形揚力はVLMへ反映していないため、Polar範囲内でも揚力と横力は薄翼VLMの推定値であり、Polarと完全に整合する解析ではない。Polarデータの端点が失速を含むか判定できないので、その範囲内であっても失速の有無は判定しない。結果画面にこの制約を表示する。

尾翼タブの各尾翼テーブル直下で、現在の下書き形状に対して単体解析を実行できる。揚力・横力・誘導抵抗・Re範囲・左右のスパン方向荷重を表示し、有効なPolarが揃う場合だけ断面抵抗・総抵抗・モーメントも表示する。Polarが不足する場合は理由と翼型タブへのリンクを表示する。条件・形状・Polarの変更で結果を無効化する。結果は一時表示で保存対象ではない。

## 空力解析ケースへの全翼面接続（2026-09-28）

解析ケースの任意項目 `scope` で `wing` と `aircraft` を選ぶ。省略した旧ケースは主翼のみ。全翼面ケースはVLMのみ許可し、固定横滑り角 `beta` を追加する。迎角スイープの各点で主翼・全尾翼を一つの行列で解き、主翼の翼面積・スパン・MACと主翼MAC/4（X）を基準としてCL、CY、CDi、Cm、Cr、Cnを出す。翼面別の力・モーメント寄与も同じ主翼基準係数で保存し、合計が全機係数になる。全翼面の `cd` は現段階ではCDiそのもの。Polarは使わず、`polarIds` は空配列にする。UIとCSVに非粘性と明記し、安定性判定には使わない。解析条件・機体形状のスナップショット、翼型参照、JSON検証、スキーマ、CSV翼面別寄与へ接続済み。形状変更時の既存の要確認処理も適用する。

全翼面CLには尾翼荷重も含まれるため、主翼の構造荷重ケースには流用しない。構造荷重生成サービスが直接の使用を拒否し、構造タブの空力結果候補から除外する。

次の解析段階では、全翼面へRe別Polar由来の揚力特性を反映し、失速・Polar範囲外・相互誘導流下の局所迎角を扱う計算モデルと検証資料が必要。これができるまで全翼面のCDは誘導抵抗のみで、トリムや静安定性の合否には使用しない。トリム・縦静安定性、その後の操舵・動安定性は未実装。

形状解釈の確認資料: [XFLR5 Wing::CreateSurfaces](https://github.com/subprotocol/xflr5/blob/master/xflr5-6.10/src/objects/Wing.cpp)。XFLR5との解析結果の一致を保証するものではない。
