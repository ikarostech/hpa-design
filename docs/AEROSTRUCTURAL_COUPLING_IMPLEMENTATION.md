# 空力構造連成ソルバー 移植・実装計画

## 目的

HPADesignの既存VLM/LLTと主翼カーボンパイプ構造解析を接続し、空力荷重による主翼のたわみ・ねじれと、その変形が空力荷重へ与える影響を同じ解析内で収束させる。

本書でいう「移植」は、TR-797、ASWING、OpenAeroStruct、SHARPyのコードを直接取り込むことではない。各手法の問題設定と数値解法を参考にしながら、HPADesignの既存モデルとTypeScript実装へ段階的に導入することを指す。

## 結論

最初に実装するのは、VLMと現行の線形Euler–Bernoulli梁を不足緩和付き固定点反復で接続する、定常・静的な分割型連成ソルバーとする。

- TR-797は連成ソルバーの中核にはせず、理論最適循環分布、初期値、回帰試験用ベンチマークとして別機能にする。
- ASWINGの「変形後形状で空力と梁の平衡を同時に満たす」という定式化を長期的な到達点とする。
- OpenAeroStructのMDO構成を、連成解析完成後の空力・構造統合最適化の参考にする。
- SHARPy相当の非定常VLM、動的梁、突風、フラッターは定常連成完成後の別フェーズとする。

## 手法の役割分担

| 手法 | HPADesignで採用する役割 | 初期実装に含めないもの |
| --- | --- | --- |
| TR-797 | 揚力・翼根曲げモーメント制約下の最小誘導抵抗分布、検証基準 | 実構造重量、変形フィードバック、局所強度 |
| 分割型定常連成 | MVPの連成アルゴリズム | 動解析、連成随伴法 |

## 現状と不足機能

### 利用できる既存機能

- `src/features/analysis/services/vlmSolver.ts`: 定常VLMと循環の内部計算
- `src/features/analysis/services/lltSolver.ts`: 定常LLT
- `src/features/analysis/services/wingAnalysisMesh.ts`: 翼パネルメッシュ
- `src/features/structures/services/structuralAnalysis.ts`: 積層、`EI`、`GJ`、たわみ、断面回転、ねじれ、強度、重量
- `src/features/structures/services/structuralLoadService.ts`: 空力結果から構造荷重ケースへの変換
- `src/shared/model/job.ts`: 解析ジョブ状態の共通契約
- `src/shared/model/resultView.ts`: 解析結果表示状態の共通契約

### 現状の一方向連成

通常のVLM/LLT解析は各迎角について翼幅方向の循環、揚力、誘導抗力、形状抗力、弾性軸回りトルクを保存する。`createLoadCaseFromAerodynamicResult` は選択した迎角の実分布を構造荷重へ渡す。翼幅分布を持たない旧結果だけは、総揚力から楕円分布を作り、ねじりをゼロとする従来処理へフォールバックする。

そのため、最初の移植単位は次の3点になる。

1. VLM/LLTから翼幅方向の実荷重と空力モーメントを公開する。
2. 空力格子から梁へ力とモーメントを保存的に移送する。
3. 梁変形から空力格子を更新し、収束まで反復する。

## MVPの適用範囲

### 含める

- 定常、非圧縮、低速、付着流を前提としたVLM
- 対称飛行と片翼構造モデル
- 曲げ変位、曲げ回転、弾性ねじれ
- 空力揚力分布と弾性軸回りトルク分布
- 固定迎角解析
- 目標揚力に迎角を合わせる水平飛行トリム
- 不足緩和付き固定点反復
- 反復履歴、収束状態、残差、警告の保存
- 変形前後の空力係数、翼端変位、最大ねじれ、リザーブファクターの比較

### 含めない

- 非定常空力、突風、フラッター
- 剥離を伴う大迎角流れ
- CFD–CSD連成
- 機体剛体運動との連成
- 桁の局部座屈、Brazier扁平化、接合部破壊
- 最適化と随伴微分
- 幾何学的非線形梁

MVP結果には、線形梁と付着流VLMの適用範囲を明記する。翼端変位や回転が設定した警告閾値を超えた場合は、収束していても「大変形のため要確認」とする。

## 連成する物理量

### 空力から構造へ

VLMは、循環、パネル代表点、パネル力、パネルモーメントを含む生の `VlmPanelLoad` を `features/analysis` 内の型として出力する。荷重移送処理は、その生データを次の翼幅ストリップ表現へ変換する。

```ts
interface AerodynamicSpanLoadPoint {
  yPosition: number;
  circulation: number;
  liftPerLength: number;
  dragPerLength: number;
  pitchingMomentPerLength: number;
  torqueAboutElasticAxisPerLength: number;
}
```

- 揚力は梁の分布横荷重へ変換する。
- 抗力はMVPの梁変形には使わなくても結果として保持する。
- 空力中心と弾性軸のずれによるモーメント、および断面 `Cm` を弾性軸回りトルクへ合成する。
- 荷重移送前後で総力と弾性軸回り総モーメントが一致することを検査する。

`VlmPanelLoad` と空力固有の翼幅方向値は `features/analysis` に置く。一次元座標と標本点列だけは、空力・構造の両方で使用するドメイン非依存契約として、承認済みの `src/shared/model/distribution.ts` に置く。`features/analysis` から `features/aeroelastic` をimportしてはならない。

### 構造から空力へ

構造解析点から次を補間し、空力メッシュの各節点へ適用する。

- `deflection`: 鉛直変位
- `rotation`: 曲げによる局所スパン軸方向の変化
- `twist`: 弾性軸回りの断面回転

空力節点は、弾性軸上の変位を適用した後、コード方向の相対位置を弾性ねじれだけ回転する。平行移動と回転の順序、正方向、角度単位を単一の座標変換関数に集約する。

## 連成アルゴリズム

### 固定迎角

1. 未変形形状を `x0`、初期変位を `u0 = 0` とする。
2. `xk = deform(x0, uk)` から変形空力メッシュを作る。
3. VLMを解いて循環とパネル荷重を得る。
4. 荷重を梁節点へ保存的に移送する。
5. 構造解析を解いて生の変位 `uStructural` を得る。
6. `uNext = (1 - omega) * uk + omega * uStructural` で不足緩和する。
7. 変位残差と荷重残差が許容値以下になるまで2〜6を繰り返す。

### 目標揚力トリム

各連成反復の空力解析内で迎角を調整し、指定重量と荷重倍数から求めた目標揚力を満たす。迎角探索には、まずブラケット付き二分法またはBrent法相当の堅牢な一次元探索を使う。

局所失速モデルを導入する前は揚力と迎角がほぼ線形だが、将来の非線形化を妨げないAPIにする。

### 初期既定値

以下は実装開始時の既定値であり、検証結果を基に調整する。

| 設定 | 初期値 |
| --- | ---: |
| 最大反復回数 | 50 |
| 緩和係数 `omega` | 0.3 |
| 相対変位残差 | `1e-5` |
| 相対荷重残差 | `1e-5` |
| 目標揚力相対誤差 | `1e-4` |
| 発散判定 | 残差の連続増加または非有限値 |

残差の振動や収束停滞が確認された場合は、第2段階でAitkenの動的緩和を追加する。Full Newton法は幾何学的非線形梁と同時に検討する。

## ソース構成

依存方向 `app -> pages -> features -> shared` を維持する。空力構造連成は複数featureを本質的に組み合わせるため、明示的な統合featureを設ける。

```text
src/
  features/
    analysis/
      services/
        vlmSolver.ts                 # 循環・パネル荷重出力を追加
        wingAnalysisMesh.ts          # 変形済みメッシュ入力を許可
    structures/
      services/
        structuralAnalysis.ts        # 既存の構造解析を再利用
    aeroelastic/
      model/
        types.ts                     # 連成入力、設定、反復履歴、結果
        validation.ts
      services/
        aerodynamicLoadTransfer.ts   # パネル荷重 -> 梁荷重
        aerodynamicMeshDeformation.ts# 梁変形 -> 空力メッシュ
        staticAeroelasticSolver.ts   # 反復と収束制御
        liftTrimSolver.ts            # 目標揚力に対する迎角探索
      components/
        AeroelasticRunDrawer.tsx
        AeroelasticResults.tsx
```

`features/aeroelastic` から `features/analysis` と `features/structures` への依存は、連成という明示的なドメイン依存として限定する。既存featureが逆に `aeroelastic` をimportしてはならない。

結合を広げないため、`staticAeroelasticSolver` は実ソルバー関数を直接固定せず、feature内で定義した空力解析関数と構造解析関数を引数として受け取れる純粋なオーケストレータにする。これにより単体試験では決定論的なfake境界を利用できる。

## データモデル

最低限、次の情報を解析結果へ保存する。

- 入力した機体、構造設計、材料、飛行条件のスナップショット
- ソルバー種別と連成設定
- 収束状態: `converged | max-iterations | diverged | failed`
- 各反復の迎角、`CL`、`CDi`、総揚力、最大変位、最大ねじれ、変位残差、荷重残差
- 最終循環・荷重分布
- 最終構造結果
- 未変形形状と変形形状
- 適用範囲警告

解析実行状態には既存の `src/shared/model/job.ts`、結果表示状態には `src/shared/model/resultView.ts`、一次元分布には承認済みの `src/shared/model/distribution.ts` を利用する。

設計JSONへ永続化する場合は、入力スナップショットと結果スキーマにバージョンを持たせ、旧JSONの読み込みを維持する。

## UI計画

当面のUIでは専用の「空力構造連成」実行タブを設けない。空力解析と構造解析はそれぞれの既存画面で独立して実行し、「結果」ページで選択した空力結果と構造結果を統合表示する。

翼幅方向データの共通契約、座標規約、補間、永続化の設計は `docs/SPANWISE_DISTRIBUTION_DESIGN.md` を参照する。

- 構造結果の荷重ケースが `aerodynamicResultId` を保持している場合は、選択中の空力結果に対応する構造結果を自動選択する。
- 対応関係がない場合も、利用者が構造結果を個別選択して比較できる。
- 結果ページには空力指標、構造指標、荷重・曲げ・安全率分布、ねじりモーメント・耐荷重分布をまとめる。
- 新規の独立空力解析結果は迎角ごとの翼幅方向抗力分布を保持し、統合グラフへ表示する。旧結果は再解析が必要である。
- 実装済みの反復連成ソルバーは将来の再導入に備えて保持するが、当面の通常導線からは公開しない。

- 実行条件は既存の標準 `InspectorDrawer` またはwide drawerで編集する。
- 結果には収束/未収束を明示し、未収束結果を通常結果と同じ見た目にしない。
- 未変形/変形後の翼形状、荷重分布、たわみ、ねじれを比較表示する。
- 反復履歴は残差の対数グラフと表で確認できるようにする。
- エクスポートには連成設定、反復履歴、最終空力分布、最終構造分布を含める。
- テーブルと行操作は `docs/UI_DESIGN.md` に従う。
