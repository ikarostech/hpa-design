## 6. 空力設計

### 6.1 空力設計のタブ構成

- 翼型
- 主翼形状
- 空力解析

### 6.2 翼型を管理する

#### 翼型を追加・編集する

- 翼型座標の入力または読み込み
- 翼型名と識別子
- 厚み、キャンバーなどの表示値
- 翼型の比較と削除

#### XFoil Polar を作成する

- Reynolds 数
- Mach 数
- 迎角範囲と刻み
- Ncrit
- 解析の実行、キャンセル、再実行
- `complete` と `needs-review` の違い

#### Polar グラフを読む

- 揚力係数 `CL`
- 抗力係数 `CD`
- モーメント係数 `CM`
- 揚抗比 `L/D`
- 未収束点の扱い

<!-- スクリーンショット候補：翼型一覧、解析条件ドロワー、Polar 比較グラフ -->

### 6.3 主翼形状を定義する

#### 機体全体の設定

- 翼幅、翼面積、コード長
- テーパー比、ねじり下げ、上反角、後退角、取付角
- 静安定余裕

#### 翼幅方向セクションを編集する

- 翼幅位置と前後位置
- コード長
- ねじり角、上反角
- 翼型の割り当て
- コード方向・翼幅方向パネル数
- パネル分布方式
- 操舵面の設定

#### 形状プレビューを確認する

- 平面形
- 断面配置
- 入力エラーと警告

### 6.4 空力解析ケースを作成する

- LLT と VLM の選び方
- 迎角 sweep
- 速度、高度、Reynolds 数
- 使用する機体形状
- ケースの保存、複製、編集、削除

### 6.5 空力解析を実行する

1. 解析ケースを選ぶ
2. 入力条件を確認する
3. 「解析を実行」を選ぶ
4. ジョブの進捗を確認する
5. 必要に応じてキャンセルまたは再解析する

### 6.6 空力解析結果を読む

- `CLmax`、`CDmin`、最大 `L/D`、`CM0`
- sweep グラフの比較
- 翼幅方向の揚力・抗力・ピッチングモーメント分布
- 複数ケースの表示切り替え

## 7. 構造設計

### 7.1 構造設計のタブ構成

- 構造案
- 基準荷重
- 単独解析

### 7.2 CFRP 材料を登録する

- 縦・横弾性率 `E1 / E2`
- せん断弾性率 `G12`
- Poisson 比 `ν12`
- 引張・圧縮・せん断強度
- 密度、層厚、低減係数
- 材料注記

> [!CAUTION]
> <!-- 編集メモ：実材料では試験値・メーカー値を確認すべきこと、サンプル値を実設計へ流用しないことを書く。 -->

### 7.3 CFRP パイプと積層を定義する

- セクション長さと外径
- 材料の選択
- 積層角 `0° / +45° / -45° / 90°`
- 層数と積層順
- 上下面の部分積層
- 積層厚さ、内径、単位長さ重量の確認

### 7.4 構造特性グラフを読む

- 曲げ強度と曲げ剛性 `EI`
- ねじり強度とねじり剛性 `GJ`
- 支配層と破壊モード
- 局部座屈・Brazier 扁平化に関する警告

### 7.5 基準荷重を作成する

- 空力解析結果から作成する荷重
- 楕円分布荷重
- 手入力の分布荷重・集中荷重
- 荷重倍数と安全率
- 支持条件

### 7.6 構造解析を実行する

1. 構造案と荷重ケースを選ぶ
2. 荷重条件を確認する
3. 解析を実行する
4. 進捗と警告を確認する
5. 結果を保存・再解析する

### 7.7 構造解析結果を読む

- 重量
- 最大たわみ、最大ねじれ
- 反力と力・モーメント釣り合い
- 曲げモーメント、ねじりモーメント
- リザーブファクター
- 支配位置、支配層、破壊モード
- 層別応力

## 11. トラブルシューティング

### 設計ファイルを読み込めない

- JSON の形式
- スキーマバージョン
- 必須項目と参照 ID
- エラーメッセージのパスの読み方

### XFoil 解析が完了しない

- 入力範囲と刻み
- 翼型座標
- Reynolds 数と迎角
- 未収束点の扱い

### LLT / VLM 解析を実行できない

- 翼型 Polar の有無
- 主翼セクションと翼型参照
- パネル設定

### 構造解析を実行できない

- 材料参照
- セクション長さ、外径、積層
- 荷重ケースと支持条件

### FSI が収束しない

- 入力結果の組み合わせ
- 反復条件
- 変形量と剛性
- 警告・反復履歴の確認

### 解析中の処理を止めたい

- 各画面のキャンセル操作
- ヘッダーの解析ジョブ表示

## 12. 解析上の制約と注意事項

- 使用している理論と仮定
- 適用可能な形状・荷重範囲
- 数値解の収束と結果レビュー
- 材料モデルと初期層破壊評価
- 部分積層、座屈、接合部などの未評価項目
- 実機設計へ利用する場合に必要な追加検証
