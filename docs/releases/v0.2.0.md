# v0.2.0

尾翼設計と、全翼面VLMによる静安定性の概算評価を追加しました。

## 追加・変更

- 水平尾翼・垂直尾翼の形状、取付位置・取付角、桁位置、セクションとパネル分割を編集できます。有効な変更は設計へ自動反映し、不正な入力は下書きに保持します。
- 主翼と尾翼を上面・側面の配置プレビューで確認できます。
- 安定性設計を独立ページとし、「尾翼設計」「安定性解析」のタブを配置しました。旧URLからは新しい画面へ移動します。
- 全翼面VLMでCm、Cm=0となる迎角、静安定余裕、縦・横・方向の静微係数を表示・比較できます。
- 剛体、手入力または構造解析結果から取り込んだ固定変形、FSI後の固定形状を評価できます。選択した主翼・尾翼と変形はケース内に保存します。
- 設計JSONの保存・読込と解析CSV出力に対応しました。v0.1.5のサンプル2件の読込・検証を確認しています。

## 解析範囲

全翼面VLMは薄翼・非粘性・固定形状の概算です。翼型Polar、失速、胴体、質量・必要揚力を満たすトリム、操舵余裕、追加の弾性変形、動安定性は含みません。全機解析の外部ソルバーとの数値一致は未検証です。結果は静安定性検討の目安として扱ってください。

Double Fin・Symmetric Finは未対応です。有効化された旧データは、単一尾翼に変換せず明示的に拒否します。
